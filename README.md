### Native macOS Web Crawler | Custom Commercial Desktop Application

Developed a fault-tolerant desktop application for macOS that helps users collect website and contact information without repetitive manual research. The software emphasizes reliability, efficient resource use, and a straightforward desktop experience.

- Built configurable concurrency and per-website limits to balance crawl speed with device resources.
- Implemented durable jobs, pause/resume controls, cancellation, and crash recovery.
- Added configurable crawl depth, website discovery, email and phone extraction, and export options.
- Optimized execution for low memory overhead on resource-constrained Mac hardware.

*Private commercial software • Public release planned*
